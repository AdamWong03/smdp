# Paper-stage workspace cleanup (2026-11-03)

The project footprint measured with `du -x` decreased from approximately
111 GiB to 102 GiB while the second formal NVT trajectory continued to grow.
The rounded net release is therefore approximately 9 GiB. The shared `/data1`
filesystem had about 421 GiB free after cleanup; its global free-space change
is not an exact project measurement because other users write concurrently.

## Removed from server storage

- Motion-Mode R1/R2/R3 trajectories and checkpoints
- neural-segment and SACMP data, on-policy samples and checkpoints
- old neural-SMDP experiments
- TrajCast foundation reproduction trajectories and duplicated extxyz data
- TrajCast-SMDP segment training checkpoints and 15 ns trajectory
- DSRT R2, interrupted R2, original R3 and Stable-DSRT server checkpoints
- non-best checkpoints for retained R1 and frozen R3-Opt
- obsolete official TrajCast model copies under the workspace root
- Python/test caches and temporary historical logs

## Preserved

- complete `smdp_reference_md_v1` Quartz and Water HDF5 reference data
- derived 30 fs graph cache, moved under the formal Quartz data tree
- R1 best checkpoint for the required lightweight comparison
- frozen R3-Opt best checkpoint, metrics and all formal physical trajectories
- active R3-Opt NVT replica 02 and its input files
- pinned TrajCast source and literature/source audit material
- all committed historical evidence through Git history

Deleted server artifacts have no external backup and are not recoverable except
where their small code or result summaries exist in Git history. Formal
reference data and frozen paper assets were not deleted.
