## 3. Why this matters for the method

This is the first evidence that the phase-space operator can move the **long-time physical
partition** in the right direction while losing endpoint accuracy. That is a different trade-off
from the 6 Å baselines and is potentially a method-paper result — but it is not yet a validated
method:

- one 20 ps NVE start;
- no 2.5 ns NVT;
- no diffusion;
- one seed;
- NVE is nonstationary;
- endpoint/multistep worse than both 6 Å baselines;
- analysis required a manual topology-path fix.

**Do not claim v0 "solves water" or "is better."** The correct claim is: v0 shows a
short-time-accuracy / long-time-partition trade-off that warrants a controlled NVT and seed
replication.

## 4. Pipeline bug

`scripts/run_phase_space_pipeline.py` passes a relative topology path
`equilibration/snapshots/water_5.data` to `analyze_water.py`. The analysis runs from the code
worktree, so the path does not resolve. The manual rerun used:

```bash
--topology /data1/wyd/research/foundation_mlip_adaptation/data/smdp_reference_md_v1/water/equilibration/snapshots/water_5.data
```

The automatic summary therefore shows `nve_val_20ps_analysis: incomplete` and dashes. The
trajectory itself is valid; only the analysis path failed. Fix the pipeline to resolve the
topology against the data root before the next production run.
